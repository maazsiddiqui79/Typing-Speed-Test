
# ⌨️ Typing Speed Test

A simple and interactive **Typing Speed Test** web application that measures typing speed and accuracy in real time.  
Built as a **Vibe Code project** to explore vibe coding, creative UI design, and AI-assisted development workflows.

---

## 📌 Overview

Typing Speed Test is a lightweight web-based application designed to evaluate a user's typing performance.  
It calculates Words Per Minute (WPM), tracks accuracy, and provides instant feedback with a clean and responsive interface.

This project focuses on practical frontend development and user experience optimization.

---

## 🚀 Features

- Real-time Words Per Minute (WPM) calculation  
- Accuracy tracking  
- Instant typing feedback  
- Clean and responsive UI  
- Lightweight and fast performance  
- Beginner-friendly code structure  

---

## 🛠️ Tech Stack

- **HTML** – Structure  
- **CSS** – Styling and layout  
- **JavaScript** – Typing logic and performance calculations

## ▶️ How to Run Locally
````markdown
## ▶️ How to Run Locally

1️⃣ Clone the repository  
```bash
git clone https://github.com/maazsiddiqui79/Typing-Speed-Test.git
````

2️⃣ Navigate into the project folder

```bash
cd Typing-Speed-Test
```

3️⃣ (Optional but Recommended) Create a virtual environment

```bash
python -m venv .venv
```

4️⃣ Activate the virtual environment

* On Windows:

```bash
.venv\Scripts\activate
```

* On macOS/Linux:

```bash
source .venv/bin/activate
```

5️⃣ Install required dependencies

```bash
pip install -r requirements.txt
```

6️⃣ Run the Flask application

```bash
python app.py
```

7️⃣ Open your browser and go to

```
http://127.0.0.1:5000/
```
